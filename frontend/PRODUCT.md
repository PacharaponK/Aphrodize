# Aphrodize

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

ผู้ใช้ติดตามลักษณะผิวจากภาพใบหน้าและบันทึกสุขภาพรายวัน เพื่อดูข้อมูลย้อนหลังและคำแนะนำเฉพาะบุคคล

## Capabilities and constraints

- วิเคราะห์ภาพใบหน้าแยกจากข้อมูลสุขภาพตามเวลา
- ข้อมูลรายวันประกอบด้วยเวลานอน ปริมาณน้ำดื่ม และตัวเลือกเวลาอยู่กลางแจ้ง
- ภาพรวมใช้ข้อมูลบันทึกจริงใน 7 วันล่าสุด คะแนนทดลองและความเสี่ยงไม่ใช่การวินิจฉัย
- ข้อมูลที่ไม่มีต้องแสดงสถานะว่าง ไม่สร้างค่าหรือชื่อผู้ใช้ให้ดูเหมือนข้อมูลจริง
- งานปัจจุบันปรับ Home/Dashboard เท่านั้น ไม่เปลี่ยน API สูตรคะแนน หรือระบบฝึกโมเดล

## Brand commitments

คงชื่อและโลโก้ Aphrodize โทนสีที่ผู้ใช้กำหนด ฟอนต์เดิม dark theme และวิดีโอพื้นหลังที่ผู้ใช้เลือก คง navbar ด้านบนและ hamburger บนมือถือ เว้นแต่ผู้ใช้ยืนยันการเปลี่ยนแปลง

## Evidence on hand

ผู้ใช้ยืนยันให้เริ่ม Home/Dashboard โดยอ้างอิงเลย์เอาต์ dashboard สองภาพ และปรับให้วิดีโอวนเป็นพื้นหลังหลักกึ่งกลาง ไม่อยู่ใน article; การ์ดเนื้อหาสีทึบอยู่ซ้าย–ขวา พร้อมข้อมูลรายสัปดาห์ด้านล่าง รูปอ้างอิงเป็นแนวทางการจัดหน้า ไม่ใช่แหล่งคะแนนหรือการรับรองทางการแพทย์
