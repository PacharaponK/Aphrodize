# Thailand UV map data

Boundaries: [geoBoundaries THA ADM1](https://www.geoboundaries.org/api/current/gbOpen/THA/ADM1/),
boundary ID `THA-ADM1-36821470`, represented year 2017, 77 units.
The downloaded simplified geometry is pinned to geoBoundaries commit `9469f09`:
[source GeoJSON](https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/THA/ADM1/geoBoundaries-THA-ADM1_simplified.geojson).
Source: OpenStreetMap / Wambacher. © OpenStreetMap contributors.
This dataset's metadata specifies [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/),
not the generic geoBoundaries CC BY licence. [OSM copyright](https://www.openstreetmap.org/copyright).

Adaptations: boundaries projected to local SVG coordinates, identifiers matched to
province names, and interior representative points generated for 74 provinces.
The three model locations retain their original coordinates.
The adapted database is distributed under ODbL 1.0 at
`/assets/uv-map-provinces.json`, including names, coordinates, model routing and SVG paths.
`backend/libs/uv_provinces.json` is the same adapted database without geometry paths.
The application source code retains its own licence; ODbL applies to these data files.

Province names: [kongvut/thai-province-data](https://github.com/kongvut/thai-province-data),
`api/latest/province.json`, retrieved 1 October 2026.
MIT License, Copyright (c) 2025 Kongvut Sangkla; full notice in
`PROVINCE-NAMES-LICENSE.txt` and the public `/assets/uv-map-data-license.txt`.
Province identifiers are stable English slugs, not official numeric province codes.

Rebuild after downloading the pinned GeoJSON and province registry:

```powershell
.venv/Scripts/python.exe scripts/prepare_uv_map.py boundaries.geojson provinces.json
```

UV forecast data: [Open-Meteo](https://open-meteo.com/), CC BY 4.0.
Use of the free hosted API is limited to non-commercial applications and its published quotas.
Local forecasts are generated by the project's SARIMAX models trained on TEMIS clear-sky UVIEF.
Open-Meteo daily maximum and TEMIS solar-noon values have different aggregations.
